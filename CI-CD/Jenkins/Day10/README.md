# Jenkins Day 10 — Final CI/CD Project

## Overview

Built a practical end-to-end CI/CD pipeline using Jenkins, GitHub, Docker, parameters, automated testing, deployment verification, artifact archiving, and cleanup.

## Pipeline Flow

GitHub → Jenkins → Build → Test → Docker Build → Run Container → Verify → Deploy → Archive → Cleanup

## Concepts Practiced

- Jenkins Pipeline as Code
- Jenkins parameters
- Environment variables
- Shell commands
- Docker image building
- Docker container execution
- Deployment verification
- Docker image tagging
- Artifact archiving
- Post-build actions
- Pipeline cleanup
- Development, staging, and production environments

## Result

Successfully combined the major Jenkins concepts learned during Days 1–9 into a single CI/CD pipeline.
